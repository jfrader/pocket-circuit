# Gamestruments (synced)

Runtime music is a Rust GDExtension. The descriptor and native libraries in
this directory are generated by `tools/sync_gamestruments.sh` and ignored by
git. Sync a local source build or another packaged addon with:

```bash
# release build from source
GAMESTRUMENTS_ROOT=/path/to/gamestruments ./tools/sync_gamestruments.sh

# or copy an already-packaged addon dir
GAMESTRUMENTS_ADDON_DIR=/path/to/packaged-addon ./tools/sync_gamestruments.sh
```

The release gate defaults to the pinned package under
`vendor/gamestruments/`. It requires `GamestrumentsPlayer` to load and has no
rendered-WAV fallback.
